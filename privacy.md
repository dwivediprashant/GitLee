# Privacy Policy for GitLee

GitLee is an open-source browser extension designed to automatically sync accepted LeetCode solutions to a user's GitHub repository.

## Data Collection

- GitLee does not collect, store, or sell any personal user data.
- The extension uses local storage strictly to save your user configurations and authentication tokens locally on your machine.
- GitHub authentication tokens are used solely for the purpose of communicating with the GitHub API to commit your code.
